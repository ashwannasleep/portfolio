MONU Planner

Productivity planning tool

View Live

A minimalist digital planner app built with SwiftUI and AWS Amplify, designed and developed end-to-end. MONU focuses on calm, structured planning workflows — daily tasks, habits, goals, and calendar views — wrapped in a clean, linen-inspired UI. I also explored AI-enhanced planning concepts through prototypes such as task suggestions, summaries, and productivity insights to evaluate how intelligent assistance could support daily routines.

Design & Product: Conducted user research and competitive analysis, then designed user flows, wireframes, and high-fidelity prototypes in Figma. Iterated through multiple design versions based on usability feedback.

Development & Impact: Built the native iOS app using SwiftUI and integrated AWS Amplify for authentication and cloud data sync. Successfully launched on the App Store and continue refining features based on user feedback and usage patterns.

A little bit about myself

I'm Ashley, a product-focused Full-Stack Engineer and UX/UI Designer who builds clean, intuitive digital experiences.

Projects like this strengthened my ability to move seamlessly between product design and engineering, turning ideas into polished, production-ready applications.

Why I built it

WeChat groups and RedNote were full of local information—but it was scattered, repetitive, and mixed with scams. I built Houston Echo to make useful posts easier to find again: one searchable place, organized by neighborhood and topic, with clearer community rules.

AI Chat Demo

Frontend demo

A document-aware conversation workspace with streamed responses and explicit connection states.

View Live

Attach a text or Markdown document, ask questions with that context, and export the conversation as Markdown or JSON.

Under the hood: A React client and Express backend relay streamed model responses. Provider credentials stay on the server; requests support cancellation, input limits, timeouts, and explicit failures instead of canned fallback answers.

Current status: The public demo showcases the frontend. Live model responses require a separately deployed backend with server credentials and a configured model; that connection has not yet been verified. Document context is bounded text, not a retrieval database.

MerchantIQ

Interactive demo

Turn inventory into a budget-aware replenishment plan. Adjust demand, lead time, and safety coverage before purchasing.

View Live

Import an inventory CSV or explore a 10,000-SKU sample catalog. See which products need replenishment, how many units the budget covers, and what remains unfunded.

Planning logic: Stock coverage determines priority. Demand, supplier lead time, and safety days set target quantities; whole units are allocated within the budget. Search the queue and export a filtered purchase draft.

Current status: Try the public demo with sample inventory or your own CSV. CSV data stays in the tab. No Amazon account is connected and no orders are placed. Estimates exclude open purchase orders, shipping, taxes, and supplier constraints.

A little bit about myself

I'm a software engineer who takes products from design through to deployment.

My latest project, Houston Echo, is a local community for Chinese speakers in Houston, connecting people through neighborhood conversations and shared knowledge.

I also created MONU, an iOS planner now on the App Store. I designed it in Figma, built the client in SwiftUI, and integrated AWS Amplify for authentication and cloud sync, from first concept through release.

My work has moved steadily toward the backend since: the sync layer in MONU, and a Cloudflare Worker that handles third-party API authentication for this site. I write long-form technical guides alongside the building.

Based in Houston. Open to local and remote opportunities.

MONU Planner

Shipped

Native iOS planner on the App Store — SwiftUI client with AWS Amplify authentication and cloud sync

View Live

A minimalist digital planner app built with SwiftUI and AWS Amplify, designed and developed end-to-end. MONU focuses on calm, structured planning workflows — daily tasks, habits, goals, and calendar views — wrapped in a clean, linen-inspired UI.

Design & Product: Conducted user research and competitive analysis, then designed user flows, wireframes, and high-fidelity prototypes in Figma. Iterated through multiple design versions based on usability feedback.

Development & Impact: Built the native iOS app using SwiftUI and integrated AWS Amplify for authentication and cloud data sync. Successfully launched on the App Store and continue refining features based on user feedback and usage patterns.

AI product exploration: Prototyped AI-assisted planning concepts — task suggestions, summaries, and productivity insights — to evaluate how intelligent assistance could support daily routines. These remain exploratory prototypes and are not part of the shipped app.

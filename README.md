## Featured Projects

### MONU Planner
A personal planning app built for long-term consistency and calm usability.

- Native iOS app built with SwiftUI
- Web companion and marketing site
- Cloud-backed user data with AWS services
- Focus on UX clarity, empty states, and predictable behavior

### AI Chat Demo
A UX-state–driven chat interface demonstrating real-world async and failure handling.

- Explicit loading, error, retry, and recovery states
- Demo-first experience with optional API integration
- Accessibility-conscious interaction design

### Ashpire
A career development platform for organizing job searches and applications.

- Centralized job tracking with status management
- Clean, structured UX for high-stress workflows
- Full-stack implementation with authentication and persistence

## Design Philosophy

Across projects, my focus is on:

- Clear user intent and feedback
- Predictable system behavior
- Reducing cognitive load
- Shipping features that work well under imperfect conditions

I value restraint, maintainability, and thoughtful UX over feature quantity.
